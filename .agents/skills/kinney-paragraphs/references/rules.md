# The Kinney framework

From Kinney, W. R. (2019), "The Kinney Three Paragraphs and Beyond,"
*Accounting Horizons* 33(4), 1–14.

Every paper idea passes Steps I, II, and III before implementation work begins.

---

## Step I — Three paragraphs (150–300 words total)

### What — the conceptual question

> "I am trying to find out whether ___."

- State a **causal connection**: X → Y.
- X and Y are **conceptual** factors, not empirical proxies.
- Express it as a theory or policy positing that connection.
- The sign and magnitude of d (the X→Y effect) should be implied.

### Why — importance and audience

> "It is important to find out because ___."

- **Who cares?** Investors, regulators, standard setters, managers, auditors,
  researchers.
- **Why should they care?** What does a non-zero d mean for their decisions or
  prior beliefs?
- Reach past the accounting mechanics to the theoretical, regulatory, or
  behavioral implications.
- "If all else fails, try theory" — does the contribution generalize beyond the
  specific numbers studied?
- This is the most-neglected paragraph. Push until the answer is compelling.

### How — empirical strategy

> "I will find out by ___."

- **Method:** archival, experimental, textual, or a combination.
- **Setting:** industries, period, unit of observation.
- **X̂ and Ŷ:** the empirical proxies for conceptual X and Y.
- **Identification:** how causality is established — DiD, IV, event study,
  cross-sectional variation, matching.
- **V and Z:** prior controls and concurrent controls, to satisfy "other things
  equal."

## Step II — Predictive validity

Anticipate referee concerns *before* doing the work.

### What-PV: is the conceptual claim testable?

| Question | Assessment | Stop sign? |
|---|---|---|
| Is X→Y theoretically grounded in prior theory or evidence? | | |
| Can X and Y be operationalized with available data? | | |
| Does prior literature support the plausibility of the link? | | |
| Is X→Y distinguishable from alternative explanations? | | |

**Stop sign:** if X or Y cannot be operationalized, or the conceptual link has
no theoretical grounding, stop here.

### How-PV: will the operationalization work?

| Question | Assessment | Stop sign? |
|---|---|---|
| Do X̂ and Ŷ actually measure conceptual X and Y? | | |
| Is the identification strategy credible? | | |
| Are data available and tractable within one to two years? | | |
| Are V and Z adequate for "other things equal"? | | |
| Would a skeptical TAR/JAR/JAE referee accept proxy validity? | | |

**Stop sign:** if proxies are fundamentally misaligned with the concepts, or
identification is not credible, return to Step I.

## Step III — Outcome risks

| Risk | Probability | Mitigation |
|---|---|---|
| **Type II:** d is real but too small to detect with available data | | |
| **Noise:** residual variance too large — the outcome is too noisy | | |
| **Identification failure:** a key assumption is violated | | |
| **Data unavailability:** a key variable is inaccessible | | |
| **Scope creep:** trying to answer too many questions at once | | |
| **Timing:** policy change, new guidance, or a competing paper | | |

**Stop sign:** several high-probability risks with no mitigation means the
project is probably not a good bet.

## Customizing to a setting

- **X** is a structural characteristic, policy change, or institutional feature:
  a REIT-TRS structure, proxy-advisor recommendations, auditor rotation rules,
  ESG mandates, a disclosure requirement.
- **Y** is a firm- or market-level outcome: information quality, voting
  outcomes, audit quality, competition, tax revenue, capital allocation,
  managerial behavior.
- The **Why** must land with a research audience — information environment,
  governance, audit, tax, financial reporting, capital markets, or theory of
  the firm.
- **Identification** favors natural quasi-experiments (regulatory changes,
  industry shocks, staggered adoption), cross-sectional variation, or
  instruments grounded in institutional features of the setting.
